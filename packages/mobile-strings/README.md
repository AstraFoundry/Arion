# Mobile strings

`strings.json` holds every user-facing string of the iOS and Android apps, in English (the default) and Simplified Chinese. Keys are dotted lowerCamel segments; placeholders are `{name}` and may move between languages. `pnpm mobile:generate` writes the iOS String Catalog and Swift accessors, the iOS Settings bundle (from the `iosSettings.*` keys only), the iOS permission prompts (`InfoPlist.strings` for the app and the keyboard, from the `iosPermission.*` keys only) and the Android string resources; `pnpm mobile:check` fails when they differ, or when an English permission prompt in `apps/ios/project.yml`, the Info.plist fallback, differs from the catalog. See [mobile apps](../../docs/project/mobile.md).
