# Desktop internationalization

## Runtime behavior

The interface supports English (`en`, default) and Simplified Chinese (`zh-CN`). Choose a language in Settings → General or the picker at the top of onboarding. Both entries use their autonyms, `English` and `简体中文`, in either language.

`Preferences.uiLanguage` is an additive field in preference schema v1. Older profiles without it load in English while keeping all existing choices. Unsupported stored values are repaired to English and reported through the existing preference repair diagnostics. The interface language does not select an ASR language, a model or a correction policy.

Changing language persists the preference, invalidates existing views, and refreshes native window titles and the tray tooltip on the main thread. It does not restart recognition, cancel a dictation, change focus targets, clear forms or rewrite user text. Tray menu labels resolve the current catalog when the menu opens.

## Ownership and message keys

- `packages/core/application` owns supported preference values; it has no translation or UI dependencies.
- `ui/shared/copy/copy.go` declares stable typed `copy.Key` identifiers.
- `ui/shared/copy/locales/en.json` and `zh-CN.json` are the copy source of truth, embedded in the binary; no network translation exists.
- `runtime.Store.Copy()` reads the current preference and returns an immutable catalog. Render functions resolve it once per frame. There is no mutable global active language.
- `features/uilanguage` owns the picker; pages compose it.
- Entity projections and transient validation state carry message keys. Translate them when rendering so errors already visible change language too.

```go
messages := store.Copy()
ui.Text(c, messages.Text(copy.NavGeneral))
ui.Text(c, messages.Progress(model.Done, model.Total))
```

Model identifiers/names, microphone names, user vocabulary, recognized text, physical keyboard labels and the Arion/Arion Voice brands retain their identity. Do not use translated display labels as persistent IDs. These two locales use the same decimal separator; the existing binary download size rounding is preserved.

## Formatting and integrity

Formatting templates use named placeholders, allowing translations to reorder values; placeholders may be adjacent (`{month}{day}日`). `Catalog.Progress`, `Bytes`, `Percent`, `Millis`, `Version`, `Step`, `UpdateAvailable`, `UpdateTo`, `Count`, `Duration`, `Weekday`, `Month`, `MonthDay` and `DayWords` own the supported format signatures. Interpolation is a single replacement pass: braces or percent signs in a supplied value remain literal.

Add a typed key and an entry in **both** catalogs together. Never concatenate translated sentence fragments or store translated strings in view state. Missing/empty/duplicate keys, malformed braces and changed placeholder sets are errors; missing translations do not silently fall back to English. An empty optional key represents no message.

`make i18n-check` / `pnpm i18n:check` runs catalog parity, template, formatting, native permission metadata and direct-hardcoded-copy checks using standard-library Go tests, without cgo or an interactive desktop. `pnpm test` includes this gate. The literal guard covers common text/label/placeholder/button/group/row APIs and native title/tooltip setters; runtime content and keyboard identifiers are not translations.

`pnpm desktop:check` also covers preference round trips, old/invalid profiles, picker interaction, both languages across settings, the panel/overlay, onboarding, download progress and live error retranslation. `ARION_UI_SNAPSHOTS=<dir>` saves rendered frames. `pnpm e2e:native` checks existing settings/onboarding windows and native title changes in both directions (DSK-A09).

## Native platform boundaries

`make desktop-libs` runs `scripts/stage-desktop-localizations.mjs`, deriving macOS `en.lproj` and `zh-Hans.lproj/InfoPlist.strings` from `SystemMicrophoneUsage`. MyGo packages them under `Contents/Resources`; generated resources remain ignored. The bundle declares English as its development language and both localizations. Its base microphone description must match the English catalog, checked by the i18n gate.

macOS chooses permission-prompt localization through bundle/OS language preferences, independently of the in-app picker. See Apple's [information property list localization](https://developer.apple.com/library/archive/documentation/General/Reference/InfoPlistKeyReference/Articles/AboutInformationPropertyListFiles.html) and [bundle localization keys](https://developer.apple.com/library/archive/documentation/General/Reference/InfoPlistKeyReference/Articles/CoreFoundationKeys.html). Tests validate staged `.strings` syntax and bundle contents without resetting real microphone consent.

MyGo v0.4.6 measures a line too narrow when a CJK character touches an ASCII slash (`字/分钟`), so the text wraps or truncates at its own measured width. Chinese copy writes the fullwidth slash (`字／分钟`), which is also standard Chinese typography; report the measurement to MyGo before relying on mixed CJK and ASCII punctuation in tight single-line labels.

MyGo v0.4.6 owns text editing context menus (`Copy`, `Paste`, `Undo`, `Select All`) with fixed English labels in `ui/menu.go`. Its public `Menu.EditItems()` preserves editing behavior but exposes no localization hook. These framework-owned menu labels remain English; localizing them requires an upstream hook. Keep editing commands intact instead of recreating their selection/undo behavior in Arion. OS-owned System Settings and input-source names follow the OS.

macOS native switching has been exercised locally. Windows runtime verification of this change requires the actual Windows E2E job; headless views and cross-builds are not that evidence.
