It extends [keyboard conversion research](keyboard-ime.md) and the [installed Chatterfly probes](chatterfly-installed-keyboard.md). The original complete typing request expands the earlier voice-only boundary under [ADR 017](../decisions/017-offline-pinyin-keyboard.md) and [007](../../specs/007-ime-ranking.md). The native keyboard implementation passes isolated engine/AppKit/storage checks; actual system input-source acceptance remains open.

These findings require more state than a raw string and an array of Chinese words: raw input/cursor, selected conversion segments, unconsumed suffix, preedit, absolute candidate identity, current page and final committed text have different lifetimes. Backspace rollback and partial selection must be explicit operations of the conversion engine. Paging must describe exhausted boundaries and additional candidate retrieval.

The [Doubao keyboard commit follow-up](doubao-keyboard-commit.md) now establishes a source-bound candidate-window → keyboard selection → shipped engine metadata → full host `insertText` chain, with an explicit `isASR = false` caller. Partial selection keeps selected objects and the returned suffix separate. The source-bound follow-up establishes a main-queue candidate UI refresh with weak-owner and nonempty/current-input equality guards; it does not establish an asynchronous decoder or session/generation/focus token. Complete suffix-decoder and focus ownership tracing, full key maps, dictionary formats, model weights, active enhancements and runtime quality remain unresolved; static reachability is not execution evidence.

## Implemented Arion ownership corrections

The previous host applied every incoming message to whichever controller was active, without checking session or revision. The Go adapter also accepted messages from replaced connections and did not revoke a session on disconnect. Ordinary typing during inference could leave the voice draft eligible for later replacement.

The native [composition state](../../apps/desktop/ime/macos/composition.m) and portable [IPC adapter](../../apps/desktop/infrastructure/imebridge/ime.go) now bind writes to a connection, activation and session. Capture sends `begin`; marks require strictly increasing revisions. Deactivation, disconnect, cancellation and user editing revoke ownership. Escape is session-scoped. Commits become terminal before entering the host, so repeated delivery never inserts twice; acknowledgements carry activation and session. A lost acknowledgement remains an unknown insertion outcome. Empty text is preserved on the wire.

The [IMK controller](../../apps/desktop/ime/macos/main.m) clears its provisional voice range before passing ordinary key presses to the client. It consumes Escape during a voice session. A host-requested composition end discards the unconfirmed draft. Reconnection announces the active client before other messages. Socket readers are connection-scoped, handle partial writes and disconnects, and reject oversized frames. The bootstrap closes the adapter on normal quit.

These voice corrections are independent of the new keyboard owner. The keyboard implementation uses a pinned local conversion engine, separate synchronous native typing state, native candidate window and encrypted learning. Twenty-two actual-engine/AppKit cases pass; installed input-source dispatch and external-editor behavior remain unverified. Competitor code, dictionaries and models are not implementation dependencies.

## Installation and removal corrections

The previous install deleted the installed bundle before checking that its replacement could be copied. Installation now stages all files first, preserves executable modes and bundle symlinks, and rejects unsupported filesystem entries. It rejects bundle metadata that does not declare the expected source, explicitly registers the installed bundle URL with LaunchServices before TIS, and keeps the previous bundle until parent and child are actually enabled. API success without the required state now fails installation and rolls back. On failure it restores previous bytes and requests restoration of the previous registration state; failures are reported, including a recovery location if filesystem rollback cannot complete. Public install/remove calls are serialized in-process. Querying installation also verifies installed metadata, so stale cached TIS records cannot identify an unrelated old bundle as the current source. The build links and stages the complete nested bundle under a temporary sibling before publishing it by rename, avoiding LaunchServices indexing a visible app whose executable is still being linked. Localized `InfoPlist.strings` supplies the full input-mode ID and Arion display name.

Removal previously ignored the native disable result. The native adapter now selects the existing ASCII-capable keyboard layout when Arion is selected, verifies a different current source, then disables Arion. Any selection/disable error prevents bundle deletion. A failed removal also preserves the application's system-IME preference. The selection APIs were checked against the installed Apple SDK's `TextInputSources.h`; Context7 had no matching Carbon documentation.

Six filesystem tests cover missing/unsupported payloads, registration failure, first-install failure, executable/symlink preservation, rollback failure retaining recovery bytes, and failed removal preserving the installed bundle. A bootstrap test checks preference preservation after a removal error. These use isolated temporary directories and injected registration callbacks; they do not exercise real TIS registration, selection or removal, and do not complete IME-A01.

## Implemented keyboard engine

The native keyboard uses independently licensed code and data: [librime's C API](https://github.com/rime/librime/blob/master/src/rime_api.h) in the native host, with a pinned [pinyin_simp](https://github.com/rime/rime-pinyin-simp) full-Pinyin schema/dictionary closure as an initial baseline. The [core license](https://github.com/rime/librime/blob/master/LICENSE) is BSD-3-Clause; [pinyin_simp](https://github.com/rime/rime-pinyin-simp/blob/master/LICENSE) is Apache-2.0 and its dictionary header identifies AOSP provenance. This small dictionary is not established as competitor-quality. Luna is a separate data choice with its own LGPL-3.0 terms. The pinned engine/data closure is now staged by `scripts/stage-keyboard-runtime.mjs`; exact immutable source URLs, hashes and transitive licenses are recorded in `scripts/keyboard-runtime.json`. The GPL-3.0 text is the checked-in `scripts/licenses/GPL-3.0.txt`, verified by the same digest.

Engine sessions own keyboard parsing, selected segments, candidate pages and caret state inside the IMK process, without a per-keystroke round trip to the voice coordinator. Keyboard and voice ranges have separate owners. The custom `arion_encrypted_userdb` backend persists authenticated encrypted snapshots, with no stock plaintext user dictionary or sync export. The universal nested bundle contains relocatable engine code, the prebuilt `arion_pinyin` schema and reviewed data/license closure. Bundle verification and temporary-copy signature/corruption checks pass; system first activation, OS-kept-key lifecycle and actual typing quality remain separate gates.
