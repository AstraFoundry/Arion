# 010 Clipboard history

User-approved P0: local clipboard history on macOS Apple silicon and Windows x64. Application ignore lists are explicitly excluded. [ADR 034](../docs/decisions/034-clipboard-history.md) owns persistence and internal-write isolation.

## Requirements

CLP-01: Collection is off until explicitly enabled. Disabling collection preserves existing history; enabling baselines the current clipboard without importing content copied while stopped. The history never feeds polishing, account sync, diagnostics or a network request.

CLP-02: Capture exact plain text (including line breaks), links, PNG-compatible images/screenshots, and ordered groups of ordinary local file references. Never copy referenced file bytes into history. Exclude folders and nonregular filesystem resources; a mixed group retains only ordinary files in their original order. A folder-only copy is unsupported. Legacy folder-containing records are hidden and cannot be delivered; refresh removes their pin protection so configured count/storage limits can evict them. File moves/renames are not tracked. Missing/inaccessible references cannot be pasted as valid resources.

CLP-03: Exclude Arion internal clipboard revisions, including input-target dictation staging/restoration and history paste, by operation/revision identity, never by comparing text with dictation results. When a completed dictation positively observed no editable input and successfully copied its final text, explicitly add that result to history only while collection is enabled. Permission/provider uncertainty, protected input, focus-change fallbacks, cancellation and failed/uncertain delivery do not authorize recording. A supported native focus query that explicitly reports no focused element counts as no editable input; unsupported, denied and unresponsive focus queries do not. Before session acquisition, a positive native no-input observation selects native copy delivery even when the Arion input source is selected. Unknown capability retains the selected IME route; an already-owned IME session never changes transport after failure. Preserve existing system clipboard restoration after input-target dictation. A later real user copy of identical text remains eligible. Respect concealed/transient/generated and Windows history-exclusion markers; this is not universal secret detection.

CLP-04: Identical typed payloads deduplicate, retaining stable identity and pin state while moving to the newest copy time. Pins appear first; both groups sort newest first. Persist across restarts with authenticated encryption, including images, paths, timestamps, and content-derived identities. A failed read/authentication must never be overwritten or silently replaced with an empty history.

CLP-05: A configurable global shortcut and tray entry open a compact native picker, preferring the captured editable input. Prefer caret geometry, otherwise the editable field frame; flip above and constrain to the monitor work area at screen edges. When input geometry is unavailable, place the picker beside the pointer and allow copying history without an editable target or Accessibility grant. Do not redirect to Settings solely because input geometry is missing. On macOS use a nonactivating native panel that can appear above foreign fullscreen applications and retains keyboard interaction without activating Arion or switching Spaces. Capture the external target before activation and revalidate it before one paste. The frameless picker is 270 DIP wide, content-sized from 100 to 198 DIP tall with at most four equal-height rows visible; additional history scrolls. Click a row, press Enter (including in search), or use its return icon to paste directly when the captured target is verifiable, or copy when input geometry/identity is unavailable. All three actions use the same target mode; the return icon tooltip names that action. Successful activation closes the picker. Up/Down select; Escape closes; losing focus closes. A top-right search icon reveals the search input in the header. Escape first closes active search. Search exact text and file names case-insensitively. There are no category tabs, timestamps, separate full-preview page, copy/paste footer buttons or settings-management link.

CLP-06: Image rows show small inline thumbnails. Ordinary file rows use a compact file icon and name at the same row height as text. Separate short extensions into uppercase type tags without repeating them in the visible name; keep extensionless names intact. Multi-file groups show joined names and a count tag. Preserve full filenames for accessible labels and search, and validate availability before paste. A pin/unpin button appears only while the pointer hovers over that row; at rest the only right-side action is the return icon. Pins remain first and bypass the ordinary count limit. After a 450 ms pointer dwell on truncated/flattened text, a file name or a thumbnail, show a passive native hover preview with original text, full file paths or an enlarged image. It must not take keyboard focus or intercept clicks, must fit the monitor work area, and must close when the pointer leaves that content or the picker closes. Size short previews to their content and bound preview cards to 320 × 220 DIP and text to 12 lines; image decoding stays off the UI thread with one in-flight decode and a 640-pixel edge bound. Stale results must not reopen dismissed previews. Do not expose delete, clear, reveal, a separate full-image viewer or a history management page. Automatic retention remains the cleanup mechanism. Removing unsupported folder history never modifies source files.

CLP-07: Expose only the maximum ordinary-history count through a preset selector while collection is enabled: 100/200/500/1000 records, preserving saved custom counts. Use the dictation settings disclosure and native shortcut recorder; no separate pause preference, age selector, freeform accelerator field or Apply button. First-run defaults: 200 unpinned entries, 100 MiB total payload, 10 MiB per item; byte bounds are managed internally. A new copy over the count limit evicts the oldest unpinned record. Pins bypass count eviction but consume storage; reject a new item or pin when protected data leaves insufficient capacity. Never silently truncate a payload. Settings limit edits that cannot preserve pins fail visibly. Retention runs at startup, when opening history, and on capture/pin/settings changes. Records do not expire with elapsed time and no periodic expiry maintenance runs. Ignore the retired `limits.days` preference and omit it on the next save without resetting the remaining settings.

CLP-08: Use English and Simplified Chinese catalogs, existing Sunbeam primitives, and framework-free core rules. Disk/clipboard/shortcut/positioning failures are localized and visible. The keyboard popup and direct paste have no presentation delay or success banner. Polling is bounded and does not enqueue unbounded writes or perform image decoding/disk encryption on the UI thread. Explicit no-input dictation captures are bounded using the same retention rules and serialized after in-flight history mutations. Resource jobs finish before protected app replacement. The menu-bar panel no longer displays the last dictation or its copy controls.

## Acceptance

- CLP-A01: opt-in, off/on baseline and no network/context coupling.
- CLP-A02: exact multiline/Unicode text, images without source files, ordered ordinary-file groups, folder-only/mixed/symlink exclusions, missing references and no source-file mutation.
- CLP-A03: input-target dictation writes/restores and history operations excluded; confirmed no-input copied dictation recorded only when enabled; denied/uncertain/secure/cancelled cases excluded; identical later user copy accepted; concurrent user clipboard change preserved.
- CLP-A04: stable typed dedup/pins, deterministic count/space retention with no age expiry, protected-capacity and oversize failures.
- CLP-A05: authenticated encrypted round-trip, no plaintext canaries on disk, tamper/wrong-key/read/write failures preserve previous records.
- CLP-A06: both-locale compact picker/settings states, collapsed disabled options, native shortcut recording/cancellation/conflicts, search reveal/filter/escape, hover-only pin/unpin, inline images, four-row scrolling, delayed/canceled hover previews with original content, file extension/count tags and target-aware row/Enter/search-Enter/return-icon activation in paste and copy-only modes. No destructive controls, category tabs, separate full-preview page, history management page or last-dictation menu-bar block.
- CLP-A07: shortcut conflicts, original-target activation, single paste, copy-only behavior without input geometry, and explicit permission/focus failure on the actual OS. Verify native fullscreen membership, keyboard focus, and close/reopen without activating Arion. Posting is not an acknowledgement that a host consumed content.

## Deferred

Rich-text restoration, OCR, multi-record batch/queue pasting, notes/groups, import/export, cross-device sync and file-body backups are outside P0. Native host acceptance is reported separately from headless rendering and cross-compilation.
