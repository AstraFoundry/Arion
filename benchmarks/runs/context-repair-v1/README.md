# Context repair and structural editing diagnostic evidence

`development/` retains all 72 actual LLM observations from production, structural
v3 and contextual correction candidates, exact source/context values, model/load
provenance, failures and complete source-linked assistant judgments.
`report/` also includes all 16 earlier structural-only observations from
[the companion archive](../scene-structure-v3/). Every one of the 88 outputs
was inspected; none are independent human or held-out ratings.

Fixtures are authored ASR-like/OCR-like text, not captured audio or screenshots.
`archive.json` covers both experiment directories, exact reproduction sources,
review reports and results documentation. Its hashes provide integrity checks,
not an external signature or timestamp.
