# Cleanup-aligned private-span package

Two36-case exposed synthetic regression arms share actual production CleanSpeech output. Original raw source and the complete cleanup text/deletion spans stay separate from model input. The baseline is the prior system-role/unfiltered package. The candidate adds private restoration maps, protects balanced literal quote/code contents, reuses a token for an identical kind/written span, and hides overlapping derived spelling details from the model. Full original OCR remains. Natural surrounding generation is unconstrained, and neither arm rejects any output or falls back to source.

This is a package experiment, not isolated attribution to one token technique. Candidate policy text is added even on unencoded cases and final reference key casing differs; see `packaging-clarification.json`. The original conservative normalization rubric remains unchanged pending optional user alignment. Actual semantic definition retention is distinguished from support for a particular identifier spelling. A literal request is independently checked.

All36 main/stress cases remain mandatory, with11 necessary repairs and owner/email success anchors. Freeze/protocol precede generation; fresh24 remain unavailable for inference until the full paired gate passes. The36 sources are exposed Chinese synthetic regressions, not independent or natural held-out evidence. The quoted-span regular expression is limited to balanced single-line declared delimiters, not a production parser for all escaped/nested literals.

Model is only pinned Qwen3.5-2B Q4_K_M text tensors (1,881,825,088 parameters), CPU4/GPU0, cache off, reasoning off and384 output tokens. No4B/older-Qwen/Granite inference. Actual M4/32GB is not minimum Apple Silicon16GB acceptance. Precomputed cleanup execution time is excluded from these request measurements; native/external clock limitations and serial drift preclude latency or causal speed acceptance. Sampled inference RSS excludes peak/whole-app/ASR memory. No original-language, native-lifecycle, independent-rater or release acceptance follows.

The model never receives evaluator references or review labels. Every output, including wrong OCR additions and unexpanded token errors, remains visible and counted.
