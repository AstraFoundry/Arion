# Authored OCR image fixtures

Twelve exact text images generated before the entity-evidence study using the
recorded local system font and Pillow. Text and image byte hashes are pinned in
`provenance.json` and the experiment freeze. No personal screenshot or recording
is included. Images are already generated; rendering refuses overwrite. Font
bytes are not redistributed. The images are developer-authored diagnostics, not
natural documents, window captures or held-out name generalization. Some content
is exposed development/example text, explicitly disclosed in the result report.
