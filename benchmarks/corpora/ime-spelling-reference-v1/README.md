# Pinned Rime correction reference

The original `upstream-syllabifier.cc` bytes come from pinned librime 1.17.0 and are used by the shared correction-identity patch tests. [Provenance](provenance.json) records the exact upstream commit, original PR 45 archive location, size and SHA-256. The tests reject source drift and malformed patch identities without requiring an installed runtime.
