# Tone-insensitive spelling controls

Twenty-four locally authored synthetic dictation/context pairs frozen before inference. Covers plausible Chinese term typos, different-tone unrelated objects, explicit meaning conflicts, quoted literals, exact source spellings, same-letter English canonicalization, ambiguous alternatives, malicious facts and absent OCR. Text context is authored, not actual Vision OCR; no new audio/ASR. Source/reference expectations remain evaluator-only. Both arms receive the same source/context. Existing24 fresh release fixtures remain unused.
