音声入力は、オンのあいだ話したことをすべて聞いています。だからこそ、どんな機能よりも大切な問いがあります。音声はどこへ行くのか。Arion の答えは短く、あなたのコンピューターに残ります。音声から生まれたテキストも同じです。

## デバイスに残るもの

<kbd>⌥</kbd> <kbd>Space</kbd> を押すと、Arion は音声をメモリーに録音し、コンピューター上のモデルで認識して、カーソルの位置に入力します。音声は進行中の音声入力のあいだだけ保持され、終わると破棄されます。下書きと修正も同じです。

<embed-frame src="/blog/where-your-dictation-goes/shortcut.html" title="ショートカットを試す" ratio="16/7" caption="フレーム内で ⌥ Space を押すかクリックすると、模擬の音声入力が始まり、もう一度で終わります。何も録音されません。"></embed-frame>

Arion に教えた単語もデバイスに残ります。入力された単語を修正すると、次回からその修正が取り消し付きで適用されます。

<dictation-pill state="learned" term="Arion" label="Arion という単語を学習したことを示す音声入力ピルと、取り消しボタン" caption="修正後のピル。学習した単語はデバイス上に暗号化して保存されます。"></dictation-pill>

承認済みと学習済みの語彙は AES-256-GCM で暗号化されます。鍵はデバイス上で生成され、macOS ではログインキーチェーンに、Windows では DPAPI で保護されて保管されます。[^keys]

## ネットワークを使うもの

三つだけで、どれもあなたが話した内容は含みません。

| リクエスト | 送るもの | タイミング |
| --- | --- | --- |
| モデルのダウンロード | 公開されたモデルファイルの要求。各ファイルは固定の SHA-256 ダイジェストで検証 | 初回利用前に一度 |
| アップデートの確認 | 内容やデバイス識別子は含まない | 自動。オフにできます |
| サインインとクラウド整文 | 認識したテキストと有効にしたコンテキスト。音声は送らない | サインインまたはプロバイダー接続時のみ |

モデルのダウンロード後、音声入力にネットワークは一切不要です。Arion にはクラウド音声認識もテレメトリーもありません。

<aside>

**同期はまだ利用できません。** 設計は仕様で決まっています。各レコードはアップロード前にデバイス上で暗号化され、読めるのはあなたのデバイスだけです。

</aside>

## 自分で確かめる

Arion は AGPL-3.0 のオープンソースなので、この記事の言葉を信じる必要はありません。新しいクローンからビルドしてみてください。

```sh
git clone https://github.com/AstraFoundry/Arion.git
cd Arion
make install
make desktop-build
```

そのあと Wi-Fi をオフにして音声入力してみてください。ここに書いたことが正しくなくなったら、それはバグです。[プライバシーのページ](/privacy/)と仕様[^spec]は、コードと同じ変更セットで更新されます。

[^keys]: 鍵がない場合や整合性チェックに失敗した場合はエラーになります。Arion が語彙を平文で保存する方式に戻ることはありません。

[^spec]: リポジトリの[仕様 005：プライバシー](https://github.com/AstraFoundry/Arion/blob/main/specs/005-privacy.md)。
