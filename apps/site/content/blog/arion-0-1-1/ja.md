本日、Arion 0.1.1 を公開しました。Arion にとって最初の正式リリースです。macOS 14 以降を搭載した Apple シリコンの Mac と Windows x64 で動作し、AGPL-3.0 のオープンソースとして無料でダウンロードできます。

Arion はローカルファーストの音声・ピンイン入力メソッドです。キーを押しながら話すと、中国語と英語が混ざった文もあなたのコンピューター上で認識され、キーを離すとカーソルの位置に1文がまとめて入力されます。同じアプリには、オプションの整文と音声翻訳、オフラインの全拼キーボード、暗号化されたクリップボード履歴も入っています。

最初のアルファから 0.1.1 までに 21 のプレビュー版を公開し、初期のユーザーと一緒に、実際に使われているエディターでショートカット、候補バー、整文のルール、アップデートの流れを調整してきました。0.1.1 はその成果をまとめた、日常的な利用をおすすめできる最初のバージョンです。以下では使う場面ごとにできることを紹介し、最後にまだできていないことをまとめます。

## 押して話し、離して入力

文字を入力できる場所ならどこでも、音声入力キーを押しながら話し、離すだけです。初期設定は macOS では右 Option、Windows では右 Alt です。短く1回押すとハンズフリーモードになり、もう一度押すまで聞き続けます。<kbd>Esc</kbd> を押すと何も入力せずにキャンセルします。設定では任意の単一キーや組み合わせキーを記録でき、翻訳やクリップボードのショートカットと重なる場合はその場で知らせます。

話している間、ストリーミング認識の下書きは画面下のピルにだけ表示され、書類にはまだ何も入りません。キーを離すと、Arion は最終結果をカーソル位置に1回だけ入力します。その間にウィンドウを切り替えたり、フォーカスを移したり、キャンセルしたりした場合、古い結果は破棄され、別の場所に入力されることはありません。編集できる欄にフォーカスがないときは、結果がクリップボードに残るので、好きな場所に貼り付けられます。

音声認識には Qwen3-ASR 1.7B を使います。Apple シリコンでは MLX で 8-bit、Windows では speech.cpp で Q8_0 として、CPU または Vulkan で動きます。モデルは初回利用の前に一度だけダウンロードされ（Mac では約 2.5 GB、Windows では約 2.2 GB）、ファイルごとに固定の SHA-256 ダイジェストで検証されます。その後の音声入力はオフラインで動きます。「把这个 PR merge 到 main 之前，先跑一下 CI」のように文の途中で言語が変わっても、先に言語を選ぶ必要はありません。

共有デスクで小声で話すときは、設定でソフトウェアの入力ゲインを −6 dB から +12 dB まで調整できます。パスワード欄では、コンテキストの読み取りも学習も行いません。

## 話し終えてから整える

整文は初期設定でオフです。オンにすると、キーを離したあとにローカルの言語モデルが文を整えます。「えーと」「あの」のようなつなぎ言葉を除き、「水曜、じゃなくて、木曜」のような言い直しは「木曜」だけを残し、使っているアプリに合わせて書式を整えます。

<embed-frame src="/blog/arion-0-1-1/stage.ja.html#polish" title="デモ：整文をオンにしてメールを音声入力する" ratio="16/10" caption="つなぎ言葉と言い直しを含むメール本文を話します。キーを離すと、ローカルモデルが取り消し線の部分を除き、メールの形式で挨拶と結びを加えて入力します。模擬録画です。"></embed-frame>

ローカルの整文モデルは Qwen3.5-2B（Q4_K_M GGUF、約 1.3 GB）で、macOS と Windows の両方で llama.cpp を通して動きます。**Match the app**（アプリに合わせた書式）がオンのとき、Arion はフォーカス中の入力欄の種類、Web サイトのホスト名、アプリの識別子から、音声入力ごとにシーンを選びます。シーンはチャット、メール、仕事のメッセージ、AI アシスタントへのプロンプト、検索、リストの6種類です。シーンが決めるのはレイアウトだけで、内容は変えません。判断に使うのはこれらのメタデータだけで、入力欄の文字は読みません。[^scene]

句読点には4つのモードがあります。スマート、すべて付ける、文末の句点を省く、そして中国語の画面でのみ選べる、句読点の代わりにスペースを入れるモードです。整文にカーソル周辺や現在のウィンドウの文字を参考にさせて、同じ音の人名や用語を正しく書き分けることもできます。これらの文字は OS のアクセシビリティ API で読み取り、スクリーンショットは撮らず、デバイス上でのみ使います。[^context]

整文はキーを離したあとに1回だけ実行します。以前のビルドでは話している最中に整文のプレビューを表示していましたが、測定してみるとプレビューは必ず最終結果に置き換えられ、入力される文字を変えたことは一度もありませんでした。そこでこの処理を取り除き、その計算資源を認識に回しました。[^final]

クラウドのモデルを使いたい場合は、ChatGPT でサインインするか、OpenAI、Anthropic、Google Gemini、DeepSeek、OpenRouter の API キーを追加できます。Arion がリクエストを送るのは、クラウドのエンジンを選び、プロバイダーを接続し、モデルを選んだあとだけです。送る内容は認識後のテキスト、シーン、呼び出された語彙に限られます。音声、カーソルとウィンドウのコンテキスト、音声入力の履歴はデバイスに残ります。API キーはプロバイダーごとに OS の資格情報ストアへ別々に保存されるので、プロバイダーを切り替えても上書きされません。

## もう1つのキーで翻訳

音声翻訳には専用のショートカットがあり、macOS では右 Command、Windows では右 Ctrl が初期設定です。押しながら日本語で話すと、Arion は話した内容を認識し、同じ音の語や固有名詞を直してから、翻訳先の言語で文を入力します。

<embed-frame src="/blog/arion-0-1-1/stage.ja.html#translate" title="デモ：右 Command を押して日本語で話し、英語で返信する" ratio="16/10" caption="同僚が英語で質問しています。右 Command を押して日本語で答えると、ピルには日本語の下書きが表示され、キーを離すと英訳が入力されます。模擬録画です。"></embed-frame>

翻訳先は12言語から選べます。English、简体中文、繁體中文、日本語、한국어、Español、Français、Deutsch、Português、Italiano、Русский、العربية です。翻訳は整文と同じローカルまたはクラウドのモデルを使うため、整文をオフにしていても翻訳キーを押せば動きます。モデルがない、タイムアウトした、出力が検証を通らなかった場合、翻訳は失敗としてピルに表示され、翻訳されていない原文が会話に入力されることはありません。原文はそのセッションのメモリにだけ残ります。訳文に加えた修正は修正学習の対象にしないので、翻訳先の言語の書き方があなたの語彙に混ざることはありません。

## 使うほど正確に

語彙は正しい表記ごとに整理されています。各項目には認識で出やすい誤った形が並び、Arion の入力メソッドを入れていれば、その語のピンインの読みも直接編集できます。正しい表記だけを登録した項目は、ローカル音声認識のホットワードとして使われます。条件を満たす学習済みの修正は、音声認識とピンインキーボードの語彙の両方に反映されます。新しく追加した項目が先頭に表示されます。

macOS のネイティブなエディターでは、Arion が入力した語をあなたが直すと、その修正を覚えて次回からあなたの表記を使い、ピルに取り消しボタンを表示します。

<dictation-pill state="learned" term="Arion" label="Arion の音声入力ピルが Arion という語を覚えたことを、取り消しボタン付きで知らせている" caption="修正のあと、ピルは覚えた語を知らせ、ワンクリックで取り消せます。"></dictation-pill>

語彙、学習した修正、クリップボード履歴は、ディスクに書き込む前に AES-256-GCM で暗号化されます。鍵はデバイス上で生成され、macOS ではキーチェーンに、Windows では DPAPI で保護して保存されます。鍵がない、または整合性の検証に失敗した場合、Arion は平文での保存に切り替えず、エラーとして止まります。[^privacy]

## 同じ入力メソッドでピンイン入力も

Arion にはオフラインの全拼入力メソッドが入っています。macOS では IMK、Windows では TSF の入力メソッドとして動き、両方で同じ Rime のスキーマ、候補の並べ替え、学習のロジックを共有します。<kbd>Shift</kbd> を軽く押すと中国語と英語が切り替わり、カーソル横のバッジが裏返って今のモードを示します。macOS の入力メニューでは全角文字と英語の句読点も切り替えられ、<kbd>Ctrl</kbd> <kbd>.</kbd> で句読点を切り替えます。

<embed-frame src="/blog/arion-0-1-1/stage.ja.html#keyboard" title="デモ：前の文脈でピンイン候補が並べ替わり、Shift で英語に切り替える" ratio="16/10" caption="「我们在婚礼上许下」（結婚式で交わした）のあとに shi yan と入力します。候補バーはいつもの順で開き、ローカルの並べ替えが前の文を参考に「誓言」（誓いの言葉）を先頭に移します。Shift を軽く押すとバッジが「中」から「A」に裏返ります。模擬録画です。"></embed-frame>

候補の並べ替えは、直前に書いた内容を参考にします。基本の層は、同じアプリで直近 120 秒以内に続けて確定した語の組み合わせだけを覚え、1回の確定で候補を上げるのは最大2つまでです。一度の選び間違いで先頭を奪われることはありません。50組の同音語で試したところ、2回目以降の出現では、語の頻度の学習だけだと意図した語が先頭に来たのは 32.2% で、前後の語の組み合わせを加えると 88.7% になりました。[^imk]

さらに、設定でローカルのニューラル並べ替えをオンにできます。これは2段階で動きます。約 4.5 MB の小さなモデルが入力の変化のたびに 100 ms の予算で並べ替え、150 ms 手が止まると、ローカルの整文モデルがカーソルの前後と現在のウィンドウの文字を参考に 900 ms の予算でもう一度判断します。候補バーは常に元の順ですぐに表示され、どちらのモデルも既存の候補の順番を変えるだけで、新しい語は作りません。macOS ではコンテキストをアクセシビリティ API で読み取り、パスワード欄や拒否リストのアプリからは読みません。Windows では今のところ、直近に確定したテキストだけを参考にします。[^ranking]

キーボードは、中国語モードでの英単語と接頭辞の補完、完全なピンインの語に対する絵文字の候補、8色とカスタムカラーから選べる候補のハイライトにも対応しています。macOS の入力メニューには **Voice input** の項目があり、そこから音声入力を始められます。

## クリップボード履歴

クリップボード履歴は初期設定でオフです。オンにすると、コピーしたテキスト、リンク、画像、ファイルの参照を記録します。<kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>V</kbd>（Windows では <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>V</kbd>）を押すと、カーソルの横に小さなピッカーが開きます。検索とピン留めができ、画像や長いテキストにポインターを重ねるとプレビューが表示されます。Return を押すと、選んだ項目を元の入力欄に貼り付けます。入力欄がないときはコピーします。

<embed-frame src="/blog/arion-0-1-1/stage.ja.html#clipboard" title="デモ：クリップボード履歴を検索してコマンドを貼り付ける" ratio="16/10" caption="カーソル位置でクリップボード履歴を開き、スクリーンショットにポインターを重ねてプレビューし、make で検索して Return を押すと、コマンドが書類に貼り付けられます。模擬録画です。"></embed-frame>

ファイルは参照だけを保存し、中身はコピーしません。フォルダーは記録しません。履歴は初期設定で200件、合計 100 MB まで保持し、それを超えるとピン留めしていない古い項目から削除します。時間の経過で消えることはありません。履歴全体は専用の鍵で暗号化して保存します。Arion が音声入力のために一時的に使うクリップボードは、履歴に入りません。[^clipboard]

## アップデート

Arion のアップデートはすべて Ed25519 で署名されており、インストール前にあなたのコンピューター上で検証します。初期設定では安定版だけを受け取ります。プレリリース版は、Settings › About で **Allow beta updates** をオンにした場合にだけ届きます。自動確認と自動ダウンロードは別々のスイッチで、自動ダウンロードは初期設定でオフです。ダウンロードしたアップデートはあなたが再起動を選ぶまで待ち、入力中の作業を中断しません。新しいバージョンのお知らせは、音声入力が終わったあとの手が空いたタイミングにだけ表示され、あとで対応することも閉じることもできます。システム通知は OS の設定に従います。

## データの置き場所

音声は音声入力をしている間だけメモリに置かれ、終わると解放されます。一時ファイルとして書き出すことはありません。認識の下書きと整文の結果は診断ログに書き込みません。

Arion にクラウドの音声認識はありません。モデルのダウンロードが済めば、音声入力とピンイン入力にネットワークは要りません。Arion が行う通信は、モデルのダウンロード、アップデートの確認、あなたが選んだ場合のクラウド整文、アカウントにサインインしたあとの製品のお知らせだけです。サインインして明示的に同意した場合は、日ごとの利用量も送ります。内容は日付、音声入力の回数、マイクの使用時間、文字数だけで、録音、テキスト、シーン、アプリの情報は含みません。データの流れの詳細は[「あなたの音声入力はどこへ行くのか」](/blog/where-your-dictation-goes/)にまとめています。

## はじめかた

[ダウンロードページ](/#download)でプラットフォームを選んでください。Arion の画面は英語と簡体字中国語に対応しています。Mac 版には macOS 14 以降と Apple シリコンが必要です。Windows 版は x64 のインストーラーです。初回起動時には、オンボーディングが必要なシステム権限を求め、音声入力キーの設定と認識モデルのダウンロードを案内し、整文と音声翻訳をオンにするかを選べます。

すでにアルファ版を使っている場合は、Settings › About でアップデートを確認してください。0.1.1 が表示されない場合は、一度だけ手動でダウンロードしてインストールしてください。

ソースからビルドする場合は、リポジトリを clone して次を実行します。

```sh
make install
make build desktop
```

## まだできていないこと

これまでのリリースノートでは毎回、受け入れ検証の範囲を書いてきました。今回も同じです。

- **複数デバイスの同期はまだ提供していません。** 暗号化の境界は仕様に書かれています。語彙の各レコードはアップロード前にデバイス上で暗号化され、中継サーバーが扱うのは暗号文だけです。デスクトップ側のデバイス登録はまだ完成していません。
- **修正からの学習は macOS のネイティブなエディターでのみ動きます。** Windows では語彙を手動で管理できます。
- **Windows のキーボードの文脈による並べ替えは、直近に確定したテキストだけを使います。** カーソルやウィンドウの内容はまだ読みません。
- **英語と簡体字中国語以外の 10 の翻訳先には、個別の評価がありません。** これらは英語のルールを共有しています。クラウド整文の品質と遅延もまだベンチマークしていません。
- **Intel Mac には対応していません**（[ADR 021](https://github.com/AstraFoundry/Arion/blob/main/docs/decisions/021-apple-silicon-only-macos.md)）。

問題があれば [GitHub Issues](https://github.com/AstraFoundry/Arion/issues) で知らせてください。[Discord](https://discord.com/invite/72kh465mMm) や [Feishu](https://applink.feishu.cn/client/chat/chatter/add_by_link?link_token=640t6cde-d38e-4a81-875b-7799e44b77ae) のグループもあります。何を出荷するかをどう決めているかは[「私たちが音声入力メソッドを実験のように作る理由」](/blog/building-like-an-experiment/)に書きました。

アルファ期間中に問題を報告し、再現手順を録画し、提案を送ってくれたすべての方に感謝します。
