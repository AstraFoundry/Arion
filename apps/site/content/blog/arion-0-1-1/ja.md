本日、最初の正式リリースとなる Arion 0.1.1 を公開しました。Apple シリコン搭載の Mac（macOS 14 以降）と Windows x64 に対応し、AGPL-3.0 のオープンソースとして無料でダウンロードできます。

Arion はローカルファーストの音声・ピンイン入力メソッドです。キーを押しながら話すと、中国語と英語が混ざった文もコンピューター上で認識され、キーを離すとカーソル位置に1文が入力されます。同じアプリに、オプションの整文と音声翻訳、オフラインの全拼キーボード、暗号化されたクリップボード履歴も入っています。

最初のアルファから 0.1.1 までに 21 のプレビュー版を公開し、初期のユーザーと一緒に、普段使っているエディターでショートカット、候補バー、整文のルール、アップデートの流れを調整してきました。日常的な利用をおすすめできる最初のバージョンです。

## 押して話し、離して入力

文字を入力できる場所ならどこでも、macOS では右 Option、Windows では右 Alt を押しながら話し、キーを離すと入力されます。短く1回押すとハンズフリーモードに切り替わり、もう一度押すまで聞き続けます（<kbd>Esc</kbd> でキャンセル）。設定では任意の単一キーや組み合わせキーに変更でき、翻訳やクリップボードのショートカットと重なる場合はその場で知らせます。

話している間、認識中の下書きは画面下のピルに表示され、キーを離した時点で最終結果がカーソル位置に1回だけ入力されます。途中でウィンドウを切り替えたり、フォーカスを移したり、キャンセルしたりした場合は、その結果を破棄して別のウィンドウへの誤入力を防ぎます。編集できる欄にフォーカスがないときはクリップボードに入るため、好きな場所に貼り付けられます。

音声認識には Qwen3-ASR 1.7B を使い、Apple シリコンでは MLX（8-bit）、Windows では speech.cpp（Q8_0、CPU または Vulkan）で動きます。モデルは初回利用の前に一度だけダウンロードされ（Mac 約 2.5 GB、Windows 約 2.2 GB）、ファイルごとに固定の SHA-256 ダイジェストで検証したあとはオフラインで動作します。「把这个 PR merge 到 main 之前，先跑一下 CI」のように文の途中で言語が切り替わっても、事前のモード変更は要りません。

共有デスクで小声で話すときは、設定でソフトウェアの入力ゲインを −6 dB から +12 dB まで調整できます。パスワード欄では、コンテキストの読み取りも学習も行いません。

## 話し終えてから整える

整文は初期設定でオフです。オンにすると、キーを離したあとにローカルの言語モデルが文を整えます。「えーと」「あの」のようなつなぎ言葉を除き、「水曜、じゃなくて、木曜」のような言い直しは「木曜」だけを残し、使っているアプリに合わせて書式を整えます。

<embed-frame src="/blog/arion-0-1-1/stage.ja.html#polish" poster="./posters/polish.ja.webp" title="デモ：整文をオンにしてメールを音声入力する" ratio="16/10" caption="つなぎ言葉と言い直しを含むメール本文を話します。キーを離すと、ローカルモデルが取り消し線の部分を除き、メールの形式で挨拶と結びを加えて入力します。模擬録画です。"></embed-frame>

ローカルの整文モデルは Qwen3.5-2B（Q4_K_M GGUF、約 1.3 GB）で、macOS と Windows の両方で llama.cpp を通して動きます。**Match the app**（アプリに合わせた書式）がオンのとき、Arion はフォーカス中の入力欄の種類、Web サイトのホスト名、アプリの識別子から、チャット、メール、仕事のメッセージ、AI アシスタントへのプロンプト、検索、リストの6種類のシーンを選びます。シーンは文面を変えずにレイアウトだけを調整し、判定にはこれらのメタデータのみを使って入力欄の本文は読みません。[^scene]

句読点には4つのモードがあります。スマート、すべて付ける、文末の句点を省く、そして中国語の画面で選べる「句読点の代わりにスペースを入れる」モードです。整文にカーソル周辺や現在のウィンドウの文字を参照させて、同音の人名や用語を書き分けることもできます。これらの文字は OS のアクセシビリティ API で読み取り、スクリーンショットは撮らずにデバイス上でのみ処理します。[^context]

以前のビルドでは話している最中にも整文のプレビューを表示していましたが、測定してみるとプレビューは常にキーを離したあとの最終結果で置き換えられ、最終的な入力文字が変わることはありませんでした。そこでリアルタイムのプレビューを廃止し、その計算資源を音声認識に回しています。[^final]

クラウドのモデルを使いたい場合は、ChatGPT でサインインするか、OpenAI、Anthropic、Google Gemini、DeepSeek、OpenRouter の API キーを追加できます。クラウドのエンジンを選び、プロバイダーを接続してモデルを指定したときに限り、認識後のテキスト、シーン、一致した語彙項目だけを送ります。音声、カーソルとウィンドウのコンテキスト、音声入力の履歴はデバイスに残ります。API キーはプロバイダーごとに OS の資格情報ストアへ別々に保存されるため、プロバイダーを切り替えても他のキーはそのまま残ります。

## もう1つのキーで翻訳

音声翻訳には専用のショートカットがあり、macOS では右 Command、Windows では右 Ctrl が初期設定です。押しながら手元の言語で話すと、Arion が内容を認識して同音異義語や固有名詞を整え、翻訳先の言語で文を入力します。

<embed-frame src="/blog/arion-0-1-1/stage.ja.html#translate" poster="./posters/translate.ja.webp" title="デモ：右 Command を押して日本語で話し、英語で返信する" ratio="16/10" caption="同僚が英語で質問しています。右 Command を押して日本語で答えると、ピルには日本語の下書きが表示され、キーを離すと英訳が入力されます。模擬録画です。"></embed-frame>

翻訳先は12言語から選べます。English、简体中文、繁體中文、日本語、한국어、Español、Français、Deutsch、Português、Italiano、Русский、العربية です。翻訳は整文と同じローカルまたはクラウドのモデルを使うため、整文をオフにしていてもそのまま動きます。モデルがない、タイムアウトした、出力が検証を通らなかった場合はピルにエラーを表示して入力欄には何も書き込まず、原文はそのセッションのメモリにだけ残します。訳文への手直しは学習対象から外れるため、翻訳先の言語の表記が自分の語彙に混ざることはありません。

## 使うほど正確に

語彙は正しい表記ごとにまとめられています。各項目には誤認識されやすい表記を登録でき、Arion の入力メソッドを入れていればピンインの読みも直接編集できます。正しい表記だけを登録した項目はローカル音声認識のホットワードになり、条件を満たす学習済みの修正は音声認識とピンインキーボードの語彙の両方に反映されます。新しく追加した項目が先頭に並びます。

macOS のネイティブなエディターでは、Arion が入力した語を直すとその修正を記憶し、次回からあなたの表記を使います。

<dictation-pill state="learned" term="Arion" label="Arion の音声入力ピルが Arion という語を覚えたことを、取り消しボタン付きで知らせている" caption="修正のあと、ピルは覚えた語を知らせ、ワンクリックで取り消せます。"></dictation-pill>

語彙、学習した修正、クリップボード履歴は、ディスクに書き込む前に AES-256-GCM で暗号化されます。鍵はデバイス上で生成され、macOS ではキーチェーンに、Windows では DPAPI で保護して保存されます。鍵がない場合や整合性の検証に通らない場合、Arion は平文での保存に切り替えずエラーで停止します。[^privacy]

## 同じ入力メソッドでピンイン入力も

Arion はオフラインの全拼入力メソッドとしても動きます。macOS では IMK、Windows では TSF 上に実装され、両環境で同じ Rime スキーマ、候補の並べ替え、学習ロジックを共有します。<kbd>Shift</kbd> を軽く押すと中国語と英語が切り替わり、カーソル横のバッジが裏返って現在のモードを示します。macOS の入力メニューからは全角文字と英語の句読点も切り替えられ、<kbd>Ctrl</kbd> <kbd>.</kbd> でも句読点を切り替えられます。

<embed-frame src="/blog/arion-0-1-1/stage.ja.html#keyboard" poster="./posters/keyboard.ja.webp" title="デモ：前の文脈でピンイン候補が並べ替わり、Shift で英語に切り替える" ratio="16/10" caption="「我们在婚礼上许下」（結婚式で交わした）のあとに shi yan と入力します。候補バーはいつもの順で開き、ローカルの並べ替えが前の文を参考に「誓言」（誓いの言葉）を先頭に移します。Shift を軽く押すとバッジが「中」から「A」に裏返ります。模擬録画です。"></embed-frame>

候補の並べ替えには直前の入力内容が使われます。基本の層は、同じアプリで直近 120 秒以内に続けて確定した前後の語の組み合わせを記録し、1回の確定で候補が上がる幅を最大2つまでに抑えることで、一度の選び間違いで先頭が入れ替わらないようにしています。50組の同音語で2回目以降の出現をテストしたところ、頻度学習だけでは意図した語が先頭に来た割合は 32.2% でしたが、前後の語の組み合わせを加えると 88.7% に上がりました。[^imk]

さらに、設定で2段階のローカルニューラル並べ替えをオンにできます。入力が変わるたびに約 4.5 MB の小さなモデルが 100 ms の予算で並べ替え、150 ms 手が止まると、ローカルの整文モデルがカーソル前後と現在のウィンドウの文字を参照して 900 ms の予算でもう一度並べ替えます。候補バーは常に元の順ですぐ開き、どちらのモデルも既存の候補の順番を入れ替えるだけで新しい語は作りません。macOS ではアクセシビリティ API でコンテキストを読み取り、パスワード欄や拒否リストのアプリは除外します。Windows では現在、直近に確定したテキストだけを使います。[^ranking]

中国語モードでは英単語や接頭辞の補完、完全なピンインに対する絵文字候補も出ます。選択中の候補のハイライトは8色またはカスタムカラーから選べ、macOS の入力メニューにある **Voice input** から音声入力を始めることもできます。

## クリップボード履歴

クリップボード履歴は初期設定でオフです。オンにすると、コピーしたテキスト、リンク、画像、ファイルの参照を記録します。<kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>V</kbd>（Windows では <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>V</kbd>）でカーソル横に小さなピッカーが開き、検索やピン留めができるほか、画像や長いテキストにポインターを重ねるとプレビューが表示されます。Return を押すと元の入力欄に貼り付け、入力欄にフォーカスがないときはクリップボードにコピーします。

<embed-frame src="/blog/arion-0-1-1/stage.ja.html#clipboard" poster="./posters/clipboard.ja.webp" title="デモ：クリップボード履歴を検索してコマンドを貼り付ける" ratio="16/10" caption="カーソル位置でクリップボード履歴を開き、スクリーンショットにポインターを重ねてプレビューし、make で検索して Return を押すと、コマンドが書類に貼り付けられます。模擬録画です。"></embed-frame>

ファイルは参照だけを保存し、ファイルの中身やフォルダーは記録しません。履歴は初期設定で200件・合計 100 MB まで保持し、上限を超えるとピン留めしていない古い項目から整理するため、時間の経過で消えることはありません。履歴全体は専用の鍵で暗号化され、Arion が音声入力の挿入時に一時利用するクリップボードは履歴から除外されます。[^clipboard]

## アップデート

アップデートはすべて Ed25519 で署名され、インストール前にコンピューター上で検証されます。初期設定では安定版を受け取り、Settings › About で **Allow beta updates** をオンにするとプレリリース版が届きます。自動確認と自動ダウンロードは別々のスイッチになっており、自動ダウンロードは初期設定でオフです。ダウンロード済みのアップデートは再起動を選ぶまで待機するため、入力中の作業を妨げません。新バージョンの通知は音声入力が終わったあとの手が空いたタイミングにだけ表示され、延期や非表示を選べます。システム通知は OS の設定に従います。

## データの置き場所

音声は音声入力の間だけメモリに保持され、終了と同時に解放されるため、一時ファイルとしてディスクに書き出されることはありません。認識の下書きと整文の結果は診断ログから除外されます。

Arion にクラウドの音声認識はありません。モデルのダウンロードが済めば、音声入力とピンイン入力はオフラインで動きます。ネットワーク通信を行うのは、モデルのダウンロード、アップデートの確認、自分で有効にしたクラウド整文、そしてアカウントにサインインしたあとの製品のお知らせだけです。サインインして明示的に同意した場合は、日ごとの利用量（日付、音声入力の回数、マイクの使用時間、文字数）も送信しますが、録音、テキスト、シーン、アプリの情報は含まれません。詳しいデータの流れは[「あなたの音声入力はどこへ行くのか」](/blog/where-your-dictation-goes/)を参照してください。

## はじめかた

[ダウンロードページ](/#download)でプラットフォームを選んでください。Arion の画面表示は英語と簡体字中国語に対応しています。Mac 版は Apple シリコンと macOS 14 以降が必要で、Windows 版は x64 インストーラーです。初回起動時は認識モデルのダウンロードを確認し、必要な権限を許可してから、音声入力キーを設定して試せます。整文と音声翻訳は完了後の設定で任意に有効化できます。

すでにアルファ版を使っている場合は、Settings › About でアップデートを確認してください。0.1.1 が表示されない場合は、ダウンロードページから一度だけ手動でインストールしてください。

ソースからビルドする場合は、リポジトリを clone して次を実行します。

```sh
make install
make build desktop
```

## まだできていないこと

- 複数デバイスの同期はまだ提供していません。暗号化の境界は仕様で定義済みですが（語彙の各レコードはアップロード前にデバイス上で暗号化され、中継サーバーは暗号文のみを扱う）、デスクトップ側のデバイス登録がまだ完了していません。
- 修正からの学習は macOS のネイティブなエディターでのみ動きます。Windows では語彙を手動で編集できます。
- Windows のキーボードの文脈による並べ替えは、直近に確定したテキストだけを使い、カーソル周辺やウィンドウの内容はまだ読みません。
- 英語と簡体字中国語以外の 10 の翻訳先言語にはまだ個別のベンチマークがなく、英語の検証ルールを共有しています。クラウド整文の品質と遅延もまだベンチマークしていません。
- Intel Mac には対応していません（[ADR 021](https://github.com/AstraFoundry/Arion/blob/main/docs/decisions/021-apple-silicon-only-macos.md)）。

不具合を見つけた場合は [GitHub Issues](https://github.com/AstraFoundry/Arion/issues) で知らせてください。[Discord](https://discord.com/invite/72kh465mMm) や [Feishu](https://applink.feishu.cn/client/chat/chatter/add_by_link?link_token=640t6cde-d38e-4a81-875b-7799e44b77ae) のグループでもフィードバックを受け付けています。何を出荷するかをどう決めているかは[「私たちが音声入力メソッドを実験のように作る理由」](/blog/building-like-an-experiment/)にまとめました。

アルファ期間中に試用し、問題を報告し、再現手順の録画や提案を送ってくれたすべての方に感謝します。
